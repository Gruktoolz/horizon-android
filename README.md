# Horizon Android

## Proyecto

Horizon Android es un launcher en desarrollo para jugar Minecraft Java en dispositivos Android. Reúne acceso al juego, controles táctiles configurables y herramientas para instalar recursos y recopilar diagnósticos.

La versión disponible, sus cambios y los problemas conocidos se mantienen en la página de publicaciones. Horizon sigue siendo una versión alpha.

## Funcionamiento

### Instalar y jugar
1. Consulta la página de publicaciones y descarga el APK de la versión que quieras probar.
2. Instálalo o actualiza Horizon conservando la aplicación existente.
3. Abre **Jugar** y sigue las indicaciones para descargar e instalar los recursos compatibles. La app verifica el paquete antes de usarlo; también puedes importar un ZIP preparado desde el teléfono.
4. Cuando aparezca la confirmación de recursos instalados, pulsa **JUGAR**.

No es necesario usar una computadora para instalar recursos desde la app. Minecraft y sus archivos de juego no se distribuyen con Horizon; prepara los recursos desde tu propia copia de Minecraft Java.

### Controles y herramientas
- Desde **Pausa → Opciones → Controles** puedes elegir el esquema táctil y abrir el editor para mover, redimensionar y ajustar la opacidad de los controles.
- En partida hay accesos a perspectiva, chat y pausa. Los campos de texto solicitan el teclado al enfocarse; el chat puede cerrarlo al enviar o salir.
- **Modo ligero** ofrece ajustes reducidos para dispositivos con recursos limitados. El límite de FPS es un tope configurado, no una garantía de rendimiento.
- **Reportar error** genera un informe de texto que puedes revisar y compartir desde Android. Las opciones de diagnóstico permiten exportar información adicional.

### Compatibilidad
La compatibilidad actual requiere **Android 10 o posterior, ARM64 y recursos de Minecraft Java 26.3**. Esta versión es alpha: pueden persistir cierres, bajo rendimiento o problemas de entrada, y no se ofrece como versión estable.

## Descargas

- [Ver publicaciones y descargar Horizon Android](https://github.com/Gruktoolz/horizon-android/releases)
- Los recursos se descargan desde **Jugar → Descargar recursos** o se importan como ZIP preparado desde el almacenamiento del teléfono. No hay un enlace de descarga directa de recursos en esta portada; la app gestiona la descarga y validación.

## Roadmap

- Mejorar estabilidad, consumo de memoria y rendimiento en una variedad mayor de teléfonos y tabletas.
- Corregir y validar movimiento, cámara y gestos simultáneos, incluidos servidores en línea.
- Pulir la integración del teclado, controles y accesibilidad.
- Fortalecer la descarga, importación, reparación y actualización de recursos desde Android.
- Ampliar administración de versiones, perfiles y sesiones.
- Evaluar compatibilidad con más arquitecturas y versiones de Android después de validarlas en dispositivos reales.
